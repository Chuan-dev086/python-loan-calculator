# 🏠 Simple Housing Loan Calculator (Python)

A simple housing loan calculator built with Python and tkinter.

## Features

- Equal principal and interest repayment calculation
- Input: loan amount, annual interest rate, loan term
- Output: monthly payment, total payment, total interest

## Usage

```bash
python calculator.py
```

## Tech Stack

- Python 3.14
- tkinter (Python built-in GUI library)
