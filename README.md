# 🏠 Simple Housing Loan Calculator (Python)
A simple housing loan calculator built with Python and tkinter.
## Features

- ✅ Equal principal and interest repayment calculation (等额本息)
- ✅ Equal principal repayment calculation (等额本金)
- Input: loan amount, annual interest rate, loan term
- Output: monthly payment, total payment, total interest
- Dropdown menu to select repayment method

## Usage

```bash
python calculator.py
```

## Tech Stack

- Python 3.14
- tkinter (Python built-in GUI library)

## How It Works

This calculator supports two common repayment methods used in Malaysia:

### Equal Principal and Interest (等额本息)
- Fixed monthly payment throughout the loan term
- Easier to budget as payment amount stays the same
- Higher total interest paid over time

### Equal Principal (等额本金)
- Fixed principal payment each month, interest decreases monthly
- Higher initial payment that gradually decreases
- Lower total interest paid compared to equal principal and interest
